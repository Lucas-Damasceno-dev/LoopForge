# Architecture & 7-Agent Pipeline

LoopForge enforces software engineering best practices through specialized AI agents:

1. **CPO**: Product vision and high-level epic creation.
2. **PM**: User stories breakdown and acceptance criteria.
3. **Tech Lead**: Technical spec and architecture choices.
4. **Developer**: Implementation code generation.
5. **QA**: Unit testing and verification harness.
6. **AppSec**: Static scanning (SEC-001/002/003) and LLM security audit.
7. **DevOps**: Deployability scoring, Dockerfile & CI generation.
