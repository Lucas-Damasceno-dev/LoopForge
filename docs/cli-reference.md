# CLI Reference

- `lf init`: Initializes LoopForge configuration in current directory.
- `lf plan`: Generates epic and user stories for a given vision.
- `lf run`: Triggers agentic pipeline execution.
- `lf serve`: Starts REST API, WebSockets, and Web Dashboard UI.
- `lf status`: Shows active project telemetry and status.
- `lf audit`: Audits code security, quality, and benchmarks.
- `lf release`: Prepares release notes and GitHub release tags.
- `lf completion`: Generates tab completion scripts for Bash, Zsh, and Fish.
