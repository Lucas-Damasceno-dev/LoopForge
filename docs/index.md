# LoopForge v6

> **Autonomous Agent Governance and Pipeline Orchestrator**

LoopForge is an enterprise-grade agentic AI engineering framework designed for high-assurance code generation, automated verification, security audits, and continuous delivery.

## Key Features

- **7-Agent Pipeline**: Full governance flow (`CPO` $\rightarrow$ `PM` $\rightarrow$ `Tech Lead` $\rightarrow$ `Developer` $\rightarrow$ `QA` $\rightarrow$ `AppSec` $\rightarrow$ `DevOps`).
- **Adaptive Routing**: Fast-Path execution for bug fixes and refactoring.
- **REST API & WebSockets**: Live real-time node streaming to a modern glassmorphic Web UI.
- **Multi-stack Harness**: Automatic test execution for Python (`pytest`), TypeScript/JS (`vitest`/`jest`), Go (`go test`), and Rust (`cargo test`).
- **Container Ready**: One-command deployment via Docker & Docker Compose.
