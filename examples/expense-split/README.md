# Expense Splitter

API para divisão de despesas entre amigos, com cálculo de saldos individuais e plano
de liquidação com número reduzido de transferências.

## Funcionalidades

- Criação de grupos com participantes.
- Convites com status `pending`, `active` e `expired`.
- Despesas com divisão igualitária ou customizada.
- Cálculo automático de saldos.
- Validação de consistência entre créditos e débitos.
- Plano de liquidação usando algoritmo *greedy* por maior saldo.
