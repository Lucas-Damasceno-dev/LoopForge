# 🦀 Exemplo 2: Rust CLI Dollar Quote Downloader (Gerado pelo LoopForge)

Este projeto foi **100% gerado autonomamente** pela pipeline de agentes do LoopForge a partir do prompt:
> `"CLI em Rust que baixa cotação do dólar e salva em CSV"`

## 📌 Estrutura do Projeto
- `Cargo.toml`: Manifesto Cargo de dependências
- `src/main.rs`: Aplicação principal em Rust com rotinas de exportação CSV
- `tests/test_main.rs`: Suíte de testes automatizados Rust
- `lessons.md`: Relatório executivo da pipeline do LoopForge

## ⚙️ Como Compilar e Executar
```bash
cargo build
cargo test
cargo run
```
