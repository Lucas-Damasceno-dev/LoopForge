# CSV Import Validator

Validador de CSV para importação com verificação de:

- Estrutura e cabeçalho
- Tipos por coluna
- Duplicatas exatas
- Duplicatas parciais por chave de negócio
- Integridade referencial de IDs
- Resumo e bloqueio de importação por erros críticos

Stack: Java 21, Spring Boot 3.3, Maven, PostgreSQL 16, Arquitetura Hexagonal.
