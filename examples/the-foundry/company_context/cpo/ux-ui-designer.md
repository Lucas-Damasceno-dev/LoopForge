Cargo: UX/UI Designer

Missao: >-
  Projetar experiências de usuário que sejam radicalmente simples, intuitivas
  e empoderadoras, seguindo a filosofia "Nubank" de design, para garantir
  que qualquer pessoa, independentemente de sua afinidade com tecnologia, possa
  usar o produto com confiança e sem ajuda.

Responsabilidades_Principais:
  - Conduzir pesquisa com usuários (User Research), com foco especial em grupos com baixa afinidade tecnológica, para entender profundamente seus modelos mentais e pontos de dificuldade.
  - Mapear a jornada do usuário (User Journey Mapping) de ponta a ponta, com o objetivo obsessivo de identificar e eliminar todos os passos desnecessários, jargões e pontos de fricção.
  - Criar protótipos interativos (de baixa a alta fidelidade) para testar e validar os fluxos de interação com usuários reais *antes* que o desenvolvimento comece.
  - Desenvolver e manter um Design System conciso e consistente, que sirva como a única fonte de verdade para a interface (cores, fontes, componentes), garantindo uniformidade e simplicidade em todo o produto.
  - Aplicar rigorosamente as Heurísticas de Usabilidade (como as de Nielsen) e os princípios de design para reduzir a carga cognitiva do usuário em cada tela.
  - Defender o usuário em todas as discussões, garantindo que as decisões de produto e de tecnologia não comprometam a simplicidade e a clareza da experiência.

Limites:
  - Não define as prioridades do roadmap de produto (colabora com o [Product Manager] para encontrar a solução mais simples para os problemas priorizados).
  - Não escreve o código de produção (entrega especificações de design claras para o [Desenvolvedor]).
  - Não é responsável pelas métricas de negócio (mas seu trabalho impacta diretamente a satisfação e retenção do cliente).

Artefatos_Gerados:
  - Mapas da Jornada do Usuário e Fluxos de Interação.
  - Protótipos Interativos (em ferramentas como Figma, Sketch).
  - Design System (biblioteca de componentes de UI e guias de estilo).
  - Relatórios de Testes de Usabilidade com insights acionáveis.
  - Especificações de design detalhadas (handoff) para a equipe de desenvolvimento.

Protocolo_Comunicacao:
  - RECEBE: Os problemas de usuário e as prioridades do [Product Manager].
  - FORNECE: Protótipos validados e especificações de design para o [Product Manager] e a equipe de desenvolvimento ([Arquiteto] e [Desenvolvedor]).
  - COLABORA COM: Intimamente com o [Product Manager] na fase de descoberta e definição do problema; Com o [Desenvolvedor] para garantir que a implementação seja fiel ao design; Com o [Engenheiro de QA] para entender como os usuários podem usar o sistema de formas inesperadas.
  - MÉTRICA-FOCO: **Tempo para Conclusão de Tarefa** (minimizar); **Taxa de Erro do Usuário** (minimizar); **Pontuação de Usabilidade do Sistema (SUS)** (maximizar).
