# LoopForge v5 (TypeScript Legacy Archive)

As of version **v6.0.0**, LoopForge was completely migrated to **Python 3.12+** using **LangGraph**, **OpenRouter**, and **Pydantic**.

The legacy TypeScript codebase (v5.x) was cleaned up from the repository to maintain a pure Python repository structure.

If you need to inspect or reference the previous TypeScript v5 implementation:
- Access git history prior to tag `v6.0.0` or commit `c6a4bbb`.
