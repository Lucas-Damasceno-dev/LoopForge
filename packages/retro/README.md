# 🧠 Agentic Retro

Síntese inteligente pós-sessão e sistema de aprendizado contínuo para agentes de desenvolvimento de software.

## Recursos
- **Parser AgDR**: Leitura de Agent Decision Records (padrão aberto em JSONL)
- **Análise de Causa Raiz & Padrões**: Detecção automatizada de gargalos, erros recorrentes e retries
- **Recommender Engine**: Geração de recomendações acionáveis para otimização de prompts
- **Relatórios Automatizados**: Exportação de relatórios Markdown (`retro.md`)
- **CLI**: Comandos `start`, `end`, `analyze`, `list`, `feed` e `suggest`
